# ProbeX

ProbeX is bunch of tools for deployment and support of multienvironment server debugging system. This is the product from developers to developers with a simple goal in mind: resolve testing / production bugs with less effort.


## Components
There are a few primary tools for debugging and monitoring NodeJS applications:
- __NodeJS SDK__: Provides a set of tools for fast integration with NodeJS applications.
- __CLI__: Provides a developer interface for interacting with the ProbeX system.
